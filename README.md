# 🛍️ Product Data Cleaning and Transformation

## 📌 Project Overview
This project focuses on cleaning and transforming a raw product dataset using Microsoft Excel. It contains product information from different brands and countries, including product names, prices, quantities, categories, and manufacturing dates.

## 📊 Dataset Information
- **Total Records:** 34
- **Worksheets:** Raw_Datasets, Cleaned_Data_Sets
- **File Format:** Excel (.xlsx)

## 📋 Dataset Columns
- Product ID
- Manufacturing Day
- Country Code
- Manufacturing Date
- Product Name
- Product_Name_Clean
- Brand Name
- Product Brand_Concat
- Product_&_Brand
- Price ($)
- Price_Clean
- Quantity
- Category
- Category_Clean
- Category_Type_Clean

## 🔄 Raw vs. Cleaned Data Workflow

### 1️⃣ Raw Dataset
The original dataset contains product information in its raw format.

- Inconsistent product name capitalization.
- Missing price values.
- Missing category values.
- Different data formats.

### 2️⃣ Data Cleaning
The raw dataset is processed to improve data quality.

- 🧹 Standardize product names.
- 💰 Clean and format price values.
- 🏷️ Handle missing category values.
- 📅 Standardize manufacturing dates.
- 🔍 Identify inconsistencies in the data.

### 3️⃣ Data Transformation
Excel formulas are used to create and transform columns.

- Extract manufacturing day and country code.
- Combine product names with brand names.
- Create cleaned product name columns.
- Create cleaned category columns.
- Format price values consistently.

### 4️⃣ Cleaned Dataset
The final dataset is organized and structured for further analysis.

- Consistent product names.
- Standardized categories.
- Cleaned price values.
- Structured manufacturing dates.
- Improved data consistency.
